## Reusing for another location

Change these, and copy everything else as is:
- **Business description:** swap "Los Angeles" and "California" for the new city and state.
- **Salesforce Managed Services** and **Salesforce Consulting Partner** descriptions: swap "Los Angeles" for the new city.
- **Product links:** change the tracking tags to the new city, e.g. `utm_medium=richmond&utm_city=Richmond&utm_campaign=Richmond`. Use the same tags as that profile's website link.

Google only allows one main category per profile; keep it the same across locations so they rank the same way.
